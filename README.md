# ProNovel

Desktop app for [ProNovel](https://pronovel.cc), built with [Pake](https://github.com/tw93/Pake).

## Download

Visit the [download page](https://github.com/你的用户名/ProNovel/releases) for the latest version.

## Supported Platforms

- macOS (Universal: Intel + Apple Silicon)
- Windows (64-bit)
- Linux (.deb + AppImage)

## How It's Built

This repo uses the [tw93/Pake](https://github.com/tw93/Pake) GitHub Action to automatically build desktop packages. Pushing a `v*` tag triggers a 3-platform build, and the resulting installers are attached to a GitHub Release.
